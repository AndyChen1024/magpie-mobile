# 只读用量验收

两端采用同一份[功能契约](README.md)。下表给出可重复的输入和预期行为，供共享层、SwiftUI 和 Compose 的测试按职责引用。样例中的金额单位为美元。

| 场景 | 给定输入或操作 | 应观察到的结果 |
| --- | --- | --- |
| 正常汇总与计价 | 顶层 `calls=3, errors=1, input=120, output=30, cost=0.125, unpriced=1` | 3 次调用、1 次错误、150 token。保留服务端金额精度至展示层，费用说明有 1 次未定价。 |
| 零记录与读取失败 | 先返回有效的零汇总和空明细，再分别返回缺少必需字段的响应、断网 | 第一组显示空状态；后两组分别显示数据错误、连接失败，且都可重试。 |
| 受限密钥 | 汇总返回 `403` 与 `gateway_key_held`；明细返回该密钥的 1 条记录 | 概览提示受限，请求页显示该记录。通用 `403` 与 `401` 走各自的错误提示。 |
| 分页与重试 | 51 条记录，首页 50 条；重复触发“加载更多”，第二页先失败，重试后成功返回 1 条 | 保留首页，重试的 offset 都是 50，最终显示 51 条并结束翻页。若后端返回空页，也应停止。 |
| 结果乱序 | 切换“今天 → 最近 7 天”；切换主机或替换密钥；分别让前一次请求最后完成 | 概览和明细只更新当前查询。断开后，迟到的成功响应也不会恢复旧内容。 |
| 凭据边界 | 输入 HTTP、证书不受信、服务端跨 origin 重定向、删除已保存连接 | 前三种给出连接提示，接收重定向的主机收不到凭据；删除后重新打开需要重新连接。 |
| 系统权限和生命周期 | 拒绝本地网络访问再从设置恢复；Android 旋转或重建页面，iOS 切页或回前台 | 权限拒绝与网关拒绝能区分；恢复后可重试。同一操作不会因页面重建重复追加记录。 |

**自动化。** 由 Android/KMP 对话把上表的响应和事件顺序做成共享测试输入，放在未来的 `shared/` 测试资源内。共享层测试查询参数、解析、状态和过期结果。每端用可控数据源验证页面如何呈现成功、受限和失败，至少覆盖一次重试或翻页。平台凭据和网络策略用平台测试或本地测试服务验证。测试使用合成密钥和脱敏记录。

**真实联调。** 每个平台使用一台实际手机，在同一局域网连接开启共享的 Mac。用同一密钥和时段，在主机侧用相同接口、等价授权和稳定记录核对概览及一页明细。有受限测试密钥时复核受限路径。记录客户端与 Magpie 版本、设备系统、执行场景、预期与实际；证据省略地址、密钥和真实会话内容。某类设备或凭据缺失时，注明该场景已通过哪层自动化，以及哪步实机验收待做。

**人工参与。** 首次系统授权、设备解锁及最终文案与交互体验由设备持有人参与。编写和运行回归用例、比对接口、汇总结果可以交给开发 Agent。构建、自动测试、真实主机联调和用户体验各自记录结果。
