# Magpie Mobile 工程原则（讨论稿）

以下条目供维护者讨论。定稿时应记录采纳的条目和日期。

## 平台职责

Android 使用 Kotlin 和 Jetpack Compose，iOS 使用 Swift 和 SwiftUI。导航、系统手势与生命周期由各端处理。规划中的 Kotlin Multiplatform（KMP）共享层承担两端共用的业务规则、应用状态和数据访问。描述工程现状时，以仓库中实际接入的模块为准。

## 接口与权限

按照所支持的 Magpie 版本核对字段含义、身份和权限范围。以用量页面为例，客户端需要分别呈现有权查看但记录为空、无权读取和连接失败三种结果。访问凭据只用于用户授权的主机和操作，诊断信息应脱敏。

## 验收证据

验收应覆盖用户能观察到的结果。演示数据可验证界面状态。接入真实用量时，用手机和主机在相同时间段、相同权限下核对结果。验证续聊时，在手机发送追问后回到主机，检查消息是否出现在原会话。记录实际验证的平台、环境和仍待验证的路径。
